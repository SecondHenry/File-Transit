Help

How to Send Files

  1. Log in or sign up using the form on the right side of the Transfer page.
  2. Click the Upload button or drag a file into the upload area.
  3. Only one file can be uploaded at a time (max 32 MB). Use Change File to replace the selected file.
  4. Choose your sharing method: QR Code or Link.
  5. Click Send to upload the file and generate a share code.
  6. Share the code, QR code, or download link with the recipient. The link expires in 10 minutes.

How to Receive Files

  1. Enter the share code in the Receive area on the Transfer page.
  2. Click Download to retrieve the file. If the code is invalid or expired, you will see an error message.

History

View your file transfer history on the History page. Features include:

  • Filter — Switch between All, Sent, and Received to narrow down your file list.
  • Resend — Select a file and click Resend to load it into the Transfer page for quick re-sharing.
  • Rename — Rename the display name of a selected file.
  • Download — Download the selected file to your device.
  • Delete — Remove the selected file from the list.

Click a row to select it. Only one file can be selected at a time.

Profile

When logged in, the Profile panel on the Transfer page shows your account info and up to 3 recent files for quick reference.

Account

You must log in or sign up to upload and download files. Use the Login / Sign Up toggle on the Transfer page to switch between forms.

FAQ

What is the maximum file size?

You can send files up to 32 MB per transfer.

Can I upload multiple files at once?

No. Only single file upload is supported. To send a different file, click Change File.

How long do files stay available?

Files expire after 10 minutes. Download them before the timer runs out.

What is a share code?

A short alphanumeric code generated after you send a file. Share it with the recipient so they can download your file.

Is my data secure?

Files are automatically deleted after expiration.
